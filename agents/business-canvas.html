第二层 · 找关键路径与瓶颈（价值流图 / TOC）

方法：价值流图 / TOC约束理论 / 因果循环图
  • 主线：简历触达 → 打招呼通过 → 邀约 → 到面 → 入职 → 服务农资店动销
  • 当前最卡环节（假设）：打招呼通过 → 邀约，根因多为简历质量与"关键匹配"层规则过松/过严
  • 用 TOC 思路：先把瓶颈环节的规则调准，再扩量，避免无效打招呼触顶每日上限
3

第三层 · 量化指标与归因（SMART + PDCA）

方法：SMART + PDCA / 因果链法 / MECE
  • 把"招到好销售"拆成可量化指标：周打招呼数、通过率、邀约率、到面率、入职率、转正率
  • 每层过滤规则对应一条因果链：放宽/收紧某关键词 → 影响通过率 → 影响最终入职质量
  • 用 PDCA 每周迭代一次三层过滤规则（详见"指标体系"页）
4

第四层 · 战略落地执行（三层解码）

方法：三层解码（解业务→解任务→解协同）/ 战略地图 + OKR
  • 解业务：把"招到好销售"转成具体打法——三个岗位分别怎么服务农资店老板
  • 解任务：筛选规则 CRUD、人才库建设、自动打招呼机器人（操作间隔≥5s、每日上限~95、验证码即停）
  • 解协同：共享规则库 + 各自登录态，团队对齐"谁负责哪个环节"
