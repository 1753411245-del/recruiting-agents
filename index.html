🎯 招聘智能体系列

一套纯前端、零依赖、零网络请求的招聘智能体工具。每个工具都是单个 HTML 文件，打开即用；
全部数据仅保存在你本机浏览器的 localStorage 中，不上传任何服务器。

单文件 · 免安装本地存储 · 隐私不出本机合规红线内建MIT 开源
01

JD 生成智能体

输入岗位要素，输出对外版 + 内部版双 JD，内置 8 类合规风险检测与人才画像打分表。
 02

简历筛选智能体

硬门槛 → 一票否决 → 加分加权三层过滤，A/B/C 分级 + 风险预审 + 面试邀约方案 + 台账归档。
 03

人才寻访智能体

目标公司清单、人才地图、寻访话术与渠道盘点，支持演练数据载入。
 04

结构化面试评估报告

维度评分、STAR 追问记录、录用建议自动汇总成评估报告。
 05

AI 面试题生成智能体

按岗位 / 层级 / 考察维度生成结构化面试题与追问链。
 06

招聘流程自动化看板

招聘漏斗、关键指标、阶段流转数据看板。
 07

业务解码画布

四层业务解码 + 九格画布 + 招聘漏斗瓶颈分析 + 行动清单（农资行业示例）。
使用说明：点击卡片打开对应智能体；数据保存在本机浏览器，清除浏览器数据会重置工具。
合规说明：所有工具内置歧视性标签检测，候选人隐私不出本机，AI 输出仅作辅助、须人工复核。工具不替代人工决策，不用于歧视性筛选。
